怎么读这份图纸

下面按「用户真实使用页面的先后顺序」分组：① 进入页面 → ② 页面正常态（桌面 / 移动两套布局）→ ③ 加载中 → ④ 内容缺失与待补充 → ⑤ 与其他页面的跳转关系。 每一屏上方都有一个标注条，固定回答四个问题：页面名称 / 流程位置 / 可执行操作 / 操作后去向。 再下面是交互明细表，逐条列出可点元素及其目标。

三条必须先说清楚的边界

  • 范围边界。本次只画 /about 一个页面。登录绑定、报修、活动报名、维修备案、志愿时长、 管理后台等属于后续阶段（见 README「本阶段不实现」与 docs/architecture.md 第 6 节），本图纸不涉及。
  • 编码基线。图纸里页面的结构、文案、可点元素全部来自现有代码 （src/app/about/page.tsx、src/config/about.ts、src/config/site.ts、 src/config/home.ts、src/config/navigation.ts），不是凭空设计的。
  • 不编造（口径已更新）。 原 4 项「待补充」字段已于 2026-09-13 处理完毕： 沿革与指导单位依据浙江农林大学官网与光明日报的公开报道补充，并经社团确认； 联系方式由社团提供（QQ 群 532502904）； 值班地点时间因值班室被学校收回，改写为「线下问诊活动 · 不定期借用教室」。 凡公开资料无载明的内容（如荣誉获奖年份）一律不写，不代社团臆测。

本次修订摘要（2026-09-13）： ① 补齐社团档案；② 服务范围 6 条 → 5 条并移除状态标签； ③ 联系方式区重组（删除「智慧浙农林」与「值班室」，新增 QQ 群 + 二维码）； ④ 社团档案第 3 项由「联系方式」改为「社团荣誉」，档案内不再出现联系方式； ⑤ 「常用入口」三项（认证登录 / 自助服务 / 文档仓库）移出 /about； ⑥ 新增「社团影像 · 图片走马灯」区块（社团档案上方），含四种状态规则（屏 04b）。 详见本屏各区块的「变更对照」标注。

流程总览

用户从任意位置到达 /about，再离开到别处

/about 是纯静态展示页：它不请求用户数据、不提交表单、不需要登录， 因此它的「流程」本质上是一条阅读路径，而不是一条事务流程。下面把进站与离站两条路径画全。

02  /  ABOUT

电脑医院

电脑医院是浙江农林大学的志愿性学生技术社团。我们做的事很具体：把出问题的电脑修好， 把说不清的网络问题查清，再把攒下来的经验整理成任何人都能查的文档。

02  /  ABOUT

我们是谁

第一次来不需要准备什么。把设备带上，把问题的现象尽量说清楚就够了。我们会先尝试复现问题，再决定怎么动手。

社团由学生志愿运营，不收费。遇到超出我们能力范围的操作，会直接说明并放弃，不会硬着头皮往下拆。

我们把每次维修中攒下来的经验整理成文档，公开托管在文档仓库里，任何人都可以查阅，也欢迎提交勘误与补充。

01

志愿性质，不收费

社团由学生志愿运营。遇到超出我们能力范围的操作，会直接说明并放弃，不会硬着头皮往下拆。

02

先确认，再动手

涉及可能影响保修的操作（例如更换硅脂），会先向你确认保修信息。存在风险的操作，先说明清楚并征得同意。

03

一人一机，全程留档

每台机器由一人负责到底，非紧急情况不中途转交，避免漏掉螺丝、排线或无线网卡。

成立时间与社团沿革
